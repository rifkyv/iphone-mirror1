# iPhone Mirror

Mirroring iPhone ke PC Windows lewat kabel USB, bitrate bisa diatur, delay rendah, suara game ikut ke PC.

- `ios/` app iPhone (ReplayKit broadcast + encoder hardware H.264/HEVC)
- `pc/` penerima di Windows (`run.bat`)
- `.github/workflows/build-ios.yml` build IPA otomatis di GitHub Actions

Cara setup lengkap ada di [PANDUAN.md](PANDUAN.md). Detail protokol di [PROTOCOL.md](PROTOCOL.md).
